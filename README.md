# ResQLink – SMS Based Disaster Coordination

ResQLink is an offline-first emergency communication system designed
to help people communicate with emergency responders during disasters
when internet connectivity is unavailable.

## Problem

During disasters such as floods, earthquakes, and cyclones, internet
and mobile networks may become unavailable. This makes it difficult
for affected people to send emergency requests and for rescue teams
to coordinate effectively.

## Solution

ResQLink provides a multi-channel emergency communication system using:

- SMS simulation
- Mesh network simulation
- Beacon portal
- Unified emergency dashboard
- Local data storage
- Automatic team assignment

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- Async JavaScript
- Node.js

## Features

- Offline-first communication
- Multiple communication channels
- Automatic emergency team assignment
- Local data storage
- Real-time request display
- Search and filtering
- Status tracking

## How It Works

1. User sends an emergency request.
2. The system identifies the type of emergency.
3. The request is assigned to the appropriate team.
4. The request is stored locally.
5. The unified dashboard displays and tracks the request.
